macOS 启动台不见了？3 种找回方式与替代方案

2026年9月21日 作者 Peng Tao 2 分钟阅读

  • macOS
  • 启动台
  • AppPad

升级到 macOS 26 之后，很多人的第一个反应是：启动台去哪了。它没有被删掉，只是入口和呈现方式变了，原来的肌肉记忆突然失效。

这篇写清楚三件事：现在怎么打开应用列表、原来的全屏启动台还能不能回来、以及如果都不顺手该怎么办。

一、先确认启动台还在

大部分情况下启动台本身仍然可访问，只是入口换了位置。先按顺序试：

  1. 触控板四指捏合（或张开），这是最接近旧习惯的手势。
  2. 打开「访达」→「应用程序」，所有应用都在这里。
  3. 用 聚焦搜索（Command + 空格）直接输应用名。

如果这三步里有任意一步能稳定打开网格视图，说明系统自带的能力还在，只是你更习惯以前那种全屏、可翻页、可建文件夹的启动台。

二、想要回原来的全屏启动台，有三个思路

  • 等系统设置里的开关：部分版本把入口藏在「系统设置 → 桌面与程序坞」里，值得翻一遍。
  • 用 Spotlight 替代：搜索够快，但不能像启动台那样按页摆放、拖拽分组。
  • 装一个第三方启动台：这是目前最接近原来体验的方式，代价是多一个常驻应用。

三、替代方案的核心差别在哪

选第三方启动台时，真正影响日常使用的是这几件事，而不是界面好不好看：

  1. 能不能扫描到全部应用，包括放在自定义目录里的。
  2. 文件夹与拖拽排序是否跟原生一样顺手。
  3. 唤起方式是否够快：键盘、Dock，还是触控板手势。
  4. 是否常驻内存，会不会拖慢机器。

我们在做的 AppPad 换了个思路：不要求你先回到桌面，而是把应用库按场景分进分类、放在光标旁，用快捷键、菜单栏或 Dock 唤起；想按页摆放图标时，它也有网格视图（Pro），文件夹、拖拽排序与键盘导航都在。它目前还在开发中，项目页 有完整的功能说明。

小结

启动台没有消失，只是入口变了。先确认系统自带方式能不能满足你；如果不行，再考虑替代方案——决定体验的从来不是视觉，而是扫描范围、整理方式和唤起速度。
